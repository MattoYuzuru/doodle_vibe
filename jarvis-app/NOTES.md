# Джарвис: Telegram Mini App (дедлайны, план на день, заметки)

Решения пользователя (30.09.2026): основа — дизайн «вариант B» (карта с отсчётом); по подробному ТЗ пользователя
делаем React + TS + Vite + Tailwind + Framer Motion + Lucide, экраны по очереди, каждый показываем на подтверждение.
Хранилище — Telegram CloudStorage (с копией в localStorage). Сначала все экраны на тестовых данных, Moodle подключаем последним.
Порог «жёлтый» бейдж пока ≤ 3 дней, серый — дальше (пользователь решит позже, возможно 7).
