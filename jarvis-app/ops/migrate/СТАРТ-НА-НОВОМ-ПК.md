# Для Claude на новом ПК: с чего начать

Ты запущен на стационарном ПК владельца (Windows 10 Pro, пользователь `Aleksandr`, Ryzen 5 3600, 24 ГБ). Сюда переносится
сервер Telegram-бота Doodle (@Jarvis_kimmm_bot) с ноутбука владельца. Владелец — студент МИСИС; отвечай по-русски и просто.
Сессия на ноутбуке вела проект до этого и подготовила этот набор. Полный план — `ПЕРЕНОС.md` рядом (прочитай его первым).

## Что уже решено
- Раскладка дисков: программы — на C: (SSD Kingston NVMe 466 ГБ, свободно ~38 ГБ), данные — на D: (HDD 1863 ГБ):
  папка проекта `D:\moodle-work\` (в ней `jarvis-app\`, `tools\`, папки лаб), образ диска Docker/WSL — тоже на D:.
  Если владелец освободит на C: 50–60 ГБ, данные Docker лучше держать на SSD (стенды быстрее).
- Учётная запись остаётся `Aleksandr`. Значит, при переносе пути `C:\Users\User\moodle-work` в правилах бота меняются на
  `D:\moodle-work` (lab-instruction.md, env-instruction.md, assets\lt_shot.py, assets\dig_logic.py, tools\README.md), а в
  коде `homedir()\moodle-work` (lab.mjs, activity.mjs, wsl_lab.py) — на настраиваемую папку.
- Сеть (проверка 3 окт): роутер 192.168.2.1 по Wi-Fi, потерь нет, DNS исправен. Claude, npm, PyPI, GitHub, Docker Hub
  открываются. Moodle и сайт МИСИС в тот день не отвечали ни с ПК, ни с ноутбука (сбой на стороне МИСИС). Telegram
  (api.telegram.org) с ПК не ответил, с ноутбука за тем же роутером отвечал через раз — перепроверить перед переключением.

## Шаг 2 — что сделать сейчас (данные с ноутбука ещё НЕ скопированы)
1. Проверить доступность адресов заново: `doodle-proverka.cmd` (или `check-new-pc.ps1`).
2. Поставить программы тех же версий, что на ноутбуке (`laptop-versions.txt`): Node.js 24, Git, JDK 17, .NET SDK 9,
   Docker Desktop + WSL 2 с Ubuntu, k6, 7-Zip, cloudflared, LibreOffice; Python 3.12 должен лежать в
   `C:\Program Files\Python312\` (проверь, где стоит имеющийся 3.12.3); пакеты Python — `pip-user-freeze.txt`.
   Установки с правами администратора, включение WSL и перезагрузку делает владелец — давай ему готовые команды.
3. OpenClaw (`npm i -g openclaw@2026.9.6`) и вход в подписку Claude — после копирования `.openclaw` с ноутбука.
4. Сон «никогда», экран не блокировать (нужно снимкам окна LTspice) — команды дать владельцу.
5. Включить Remote Control, чтобы владелец вёл эту сессию с ноутбука.

- Секреты (токен бота, токены Moodle, `.openclaw`) не печатать и никуда не отправлять.
