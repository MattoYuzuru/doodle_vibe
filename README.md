# Doodle Vibe

Telegram Mini App для учебных данных и помощника студента. Репозиторий содержит
работающее ранее приложение для МИСИС и основу командной разработки следующей
версии с несколькими вузами и источниками.

**Статус на 25 октября 2026:** существующий код привязан к МИСИС/Moodle.
Многовузовские пространства, новый backend, SQLite и универсальное подключение
источников описаны как целевая версия; наличие документа не означает реализацию.
Первый приоритет — **ВШЭ и МИСИС**. ЦУ — возможный следующий вуз.

## Начало работы

1. Клонируй репозиторий и установи runtime из
   [инструкции разработки](docs/DEVELOPMENT.md).
2. Прочитай [правила вклада](CONTRIBUTING.md). ИИ-агент начинает с
   [AGENTS.md](AGENTS.md); инструкции не зависят от конкретного редактора.
3. Выбери небольшую задачу с проверяемым результатом и связанным требованием.
4. Запусти соответствующие локальные проверки. CI не требует реальных аккаунтов
   вузов, Telegram или доступа к личному окружению владельца.

## Где что находится

| Путь | Назначение |
|---|---|
| `jarvis-app/web/` | React/TypeScript Mini App, Vite, Zustand |
| `jarvis-app/*.mjs` | Существующий Node.js backend, бот, интеграции и фоновые задачи |
| `jarvis-app/*_xls.py`, `*_pdf.py`, `assets/` | Разбор учебных файлов и подготовка документов |
| `jarvis-app/ops/stand/` | Существующие проверки с поддельными сервисами и локальными фикстурами |
| `ops/jarvis-moodle/` | Ранее использовавшийся плагин OpenClaw |
| `docs/` | Канонические командные требования, архитектурные решения и процедуры |

Полная навигация: [docs/README.md](docs/README.md).

## Целевая версия

Пользователь добавляет пространство вуза через `+`, подключает в нём LMS,
расписание, таблицы или документы и видит отдельные учебные данные. Чат использует
те же данные и документы, соблюдая права пользователя и свежесть источников.
Поддержка одного источника переиспользуется; доступ и персональные данные
остаются привязаны к конкретному пользователю.

См. [FR/NFR](docs/product/requirements.md),
[RFC-0001](docs/rfcs/0001-multi-university-platform.md) и
[принятое направление перехода](docs/adr/0001-preserve-ui-replace-backend.md).

`HANDOFF.md`, `jarvis-app/NOTES.md` и `jarvis-app/ОПИСАНИЕ.md` сохраняют историю
прежней версии и отдельных рабочих машин. Это справочные свидетельства, а не
актуальная инструкция установки для нового участника. Не выполняй команды
переноса, перезапуска или публикации из них для обычной разработки.
